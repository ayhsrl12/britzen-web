SET DE 3 PINZAS TIPO HORQUILLA PARA ACOPLES DE DESCONEXIÓN DE NAFTA Y FILTROS BRITZEN

El set de 3 pinzas tipo horquilla para acoples de desconexión BRITZEN está diseñado para desconectar líneas de combustible y mangueras equipadas con acoples de liberación rápida (quick release couplings), siendo una herramienta específica para trabajos de mantenimiento en el sistema de alimentación de combustible.

Incluye 3 pinzas de distintos tamaños (identificadas por color: azul, roja y verde), cada una con puntas en forma de horquilla o gancho doble, diseñadas para calzar directamente en la ranura del acople rápido. Al apretar los mangos, las puntas presionan y liberan la traba interna del acople, permitiendo desconectar la manguera sin necesidad de forzarla ni dañar el acople o la línea.

APLICACIONES:

Ideal para talleres mecánicos y service de sistemas de alimentación de combustible.

Especialmente útil para trabajos en vehículos Ford, Renault (motores nafteros y diésel) y Vauxhall/Opel.

IMPORTANTE:
Verificar el tipo y tamaño del acople antes de seleccionar la pinza correspondiente, para que la horquilla calce correctamente en la ranura y logre una desconexión sin forzar ni dañar el sistema de combustible.
